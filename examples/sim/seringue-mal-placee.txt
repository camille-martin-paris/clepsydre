# Scénario de démonstration du simulateur : clepsydre-sim examples/sim/<fichier>.txt
# Les vérifications portent sur le modèle, avec ses paramètres d'exemple non mesurés ;
# elles ne vérifient aucune exigence de la pompe.

# Seringue mal placée dans le berceau : le pousseur entraîne la seringue entière. Le capteur
# de position voit le piston avancer, mais rien n'est délivré ; seul le berceau le révèle
# (SYS-REQ-006).
debit 100
avance 10min
berceau mal-placee
verifie berceau = non
# La ligne et le joint restituent d'abord le volume qu'ils avaient accumulé, quelques
# dizaines de µL à 100 mL/h ; ensuite, plus rien ne sort.
avance 10s
repere
avance 5min
verifie volume-depuis-repere < 0.05
etat
berceau en-place
repere
avance 5min
verifie volume-depuis-repere > 5
