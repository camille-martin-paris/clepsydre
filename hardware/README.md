# Sources matérielles

Ce répertoire accueillera les sources de conception matérielle de Clepsydre :

- `electronics/` : schémas et circuits imprimés ;
- `mechanics/` : plans et modèles mécaniques ;
- `bom/` : nomenclature des composants.

Son contenu est distribué sous la [CERN Open Hardware Licence v2, à réciprocité forte](../LICENSES/CERN-OHL-S-2.0.txt) (`CERN-OHL-S-2.0`), selon l'[ADR 0001](../docs/adr/0001-licences-materiel-et-documentation.md). Toute personne qui distribue un matériel fabriqué à partir de ces sources doit en rendre les sources disponibles et indiquer ses modifications.

Source de référence : https://github.com/camille-martin-paris/clepsydre
